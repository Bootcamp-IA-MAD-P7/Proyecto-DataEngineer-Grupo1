# Scripts

Aquí viven comandos reproducibles de desarrollo, calidad y demostración. Evitar comandos
manuales no documentados.

| Comando | Propósito |
|---|---|
| `python scripts/validate_specs.py` | Comprueba que cada spec HRP tiene clave Jira, objetivo y criterios de aceptación |
| `new-task-packet.ps1` | Crea un paquete de contexto para una tarea asistida por IA |
| `new-presentation-daily.ps1` | Crea una fuente diaria para la presentación |
