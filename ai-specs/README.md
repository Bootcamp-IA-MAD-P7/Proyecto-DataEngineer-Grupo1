# AI specifications

This directory is the canonical, portable AI-workflow layer adapted from the LIDR
Specboot structure. It does not grant an assistant permission to merge, close Jira,
inspect the educational generator or make unsupported claims.

- Choose a role in `agents/` for the task area.
- Load a workflow in `skills/` before planning or making a corresponding change.
- `docs/base-standards.md` remains the single source of truth.

The structure is adapted from [LIDR Specboot](https://github.com/LIDR-academy/lidr-specboot)
under its MIT licence; the content here is specific to this project.
