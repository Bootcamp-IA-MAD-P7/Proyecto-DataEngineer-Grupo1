# AI specifications

This directory is the canonical, portable AI-workflow layer for this project. It does
not grant an assistant permission to merge, close Jira, inspect the educational
generator or make unsupported claims.

- Choose a role in `agents/` for the task area.
- Load a workflow in `skills/` before planning or making a corresponding change.
- `docs/base-standards.md` remains the single source of truth.

Use these resources together with the task specification and repository quality gates
before proposing implementation changes.
