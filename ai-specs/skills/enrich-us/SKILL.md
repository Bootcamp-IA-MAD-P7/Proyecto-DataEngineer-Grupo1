# Enrich a user story

1. Read the Jira task, linked dependencies, `docs/base-standards.md` and current docs.
2. Identify missing scope, non-scope, owner, acceptance criteria, data boundary,
   security/performance requirements, tests and evidence.
3. Draft or update `docs/specs/HRP-XX-*.md`; do not fabricate Kafka facts.
4. Return a concise proposed Jira update for a human to apply or approve.
5. A task is ready only when its implementation can proceed without guessing.
