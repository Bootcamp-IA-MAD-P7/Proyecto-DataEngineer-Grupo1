# Code audit

Review against the task spec, architecture, data safety and test requirements. Report
findings as blocking, important or suggestion. Check scope creep, secret/PII exposure,
generator boundary, idempotency, error isolation, type safety, tests, docs and
operational impact. Do not approve or merge; that decision belongs to a human.
