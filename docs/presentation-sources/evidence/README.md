# Evidencia de presentación

Guarda aquí únicamente material permitido y minimizado:

- Enlaces a PRs y commits.
- Capturas de dashboards sin secretos ni payloads completos.
- Salidas resumidas de pruebas, carga o demo.
- Diagramas exportados.

Cada evidencia debe indicar fecha, tarea Jira y qué demuestra. Los datos completos de
Kafka, archivos `.env` y volúmenes de bases de datos nunca se almacenan aquí.
