## Decisión que merece una diapositiva

El offset Kafka no se confirma al recibir el mensaje. Se confirma después de que
MongoDB haya guardado el evento raw o haya demostrado que ese mismo
`topic + partition + offset` ya existía. Esto evita pérdida silenciosa y convierte la
idempotencia en una propiedad comprobable.
